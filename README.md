# 🐾 Novarakk 喵～

> ฅ^•ﻌ•^ฅ 一个为 SillyTavern 制作的个人图像生成扩展分支。

Novarakk 是用于 SillyTavern 图像生成的个人分支项目。

本项目基于原始扩展 [sillyimages](https://github.com/0xl0cal/sillyimages)。衣橱系统及其相关构思则基于 [delidgi 的 sillyimages 分支](https://github.com/delidgi/sillyimages)。
